# BioVana Data Explorer

A static, filterable explorer for **synthetic** BioVana datasets from three studies, with study and site names pseudonymised. Study Alpha / Site B includes synthetic gene-variant calls (79 genes) for 23 genotyped participants. All records are generated from the aggregate structure of the source data; none describes a real participant or sample. For demonstration only, not for analysis.

- `index.html`: the explorer (no build step)
- `data.json`: the synthetic data the page loads

Host as static files (Vercel, GitHub Pages, Netlify). Keep both files in the same folder.

# BioVana Data Explorer

A static, filterable explorer for **synthetic** BioVana datasets (BioAtlas and PROS studies). All records are generated from the aggregate structure of the source cohorts; none describes a real participant or sample. For demonstration only, not for analysis.

- `index.html`: the explorer (no build step)
- `data.json`: the synthetic data the page loads

Host as static files (Vercel, GitHub Pages, Netlify). Keep both files in the same folder.
